# Приём заявок в Yandex Cloud Functions

`index.js`: функция без зависимостей (Node.js 18+, точка входа `index.handler`).
Принимает POST с сайта med-local.ru и отправляет письмо через SMTP ящика на Timeweb.

Переменные окружения функции: `SMTP_USER`, `SMTP_PASS` (обязательные), `MAIL_TO`, `MAIL_FROM`,
`SMTP_HOST` (smtp.timeweb.ru), `SMTP_PORT` (465), `ALLOWED_ORIGINS`, `POLICY_DATE`, `RATE_LIMIT`, `DRY_RUN`.
Функция должна быть публичной (ссылка вызова без авторизации). Проверка: `<ссылка>?health=1` возвращает `ok`.

Лимит запросов хранится в памяти одного экземпляра функции, поэтому он мягкий. Защита строится на проверке Origin,
скрытом поле-ловушке, обязательном согласии и лимите размера тела.
