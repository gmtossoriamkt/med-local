# med-local.ru

Статический сайт: страницы лежат в каталогах `<раздел>/index.html`, статьи блога — в `blog/<slug>/index.html`.

## Проверки перед коммитом

Скрипт `scripts/check-injections.sh` ищет в `.html` (включая `/en`) код, внедрённый антивирусом или прокси:
подстроки `kaspersky`, `kis.v2.scr`, `gc.kis`, `127.0.0.1`, `localhost`, а также `<script src>` и `<link href>`
на домены вне белого списка (`mc.yandex.ru`, `functions.yandexcloud.net`, `med-local.ru`). При находке печатает `файл:строка` и завершается с кодом 1.

Ручной запуск по всему репозиторию:

```bash
bash scripts/check-injections.sh
```

Автоматическая проверка изменённых `.html` перед каждым коммитом (один раз после клонирования):

```bash
git config core.hooksPath .githooks
```

Если проверка сработала, откройте указанное место и удалите чужой тег. Такие скрипты обычно попадают в файл,
когда страницу сохраняют из браузера («Сохранить как») с включённым антивирусом, вместо правки исходника.
